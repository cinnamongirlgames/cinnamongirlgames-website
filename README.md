# Cinnamon Girl Games website

The website for https://cinnamongirlgames.com

It's a plain HTML website (no build step), hosted free on Cloudflare Pages.
Every time a change is saved to the `main` branch here, Cloudflare puts the new version online within a minute or two.

## What's where

- `index.html` - the homepage (the words and sections)
- `css/style.css` - the look (colours, fonts, spacing). Colours are at the top.
- `images/` - pictures and the little site icon

## Growing the site later

New pages go in their own folders, for example:

- `games/index.html` becomes cinnamongirlgames.com/games
- `blog/index.html` becomes cinnamongirlgames.com/blog
- `app/index.html` becomes cinnamongirlgames.com/app

## Cloudflare Pages settings

- Framework preset: None
- Build command: (leave empty)
- Build output directory: `/`
